# Brillo (historia 3) — Plan de implementación

**Goal:** Agregar un slider de brillo de 50 a 200 que aclara u oscurece los tonos medios sin mover el negro ni el blanco, combinado con el contraste en la misma curva 1D de salida.

**Architecture:** Dos funciones puras nuevas calculan la curva de brillo (`x^(1/b)`) y la curva combinada (primero contraste, después brillo). `Controller` guarda contraste y brillo y reescribe la curva combinada cuando cambia cualquiera de los dos. El backend de Intel no cambia. La ventana suma un tercer slider y el cableado de los sliders pasa a una función común.

**Tech Stack:** Rust stable (MSVC), Slint 1.18, IGCL (sin cambios en `src/igcl/`).

**Spec:** `docs/specs/2026-11-13-brillo-design.md`

## Global Constraints

- Solo Windows x64, toolchain `stable-x86_64-pc-windows-msvc`.
- El slider de brillo va de **50 a 200** en pasos enteros. **100 es la imagen sin modificar.**
- Curva de brillo: `brillo(b, x) = x^(1 / b)` con `b = valor / 100`. Curva escrita: `tono(c, b, x) = brillo(b, contraste(c, x))` (primero contraste, después brillo).
- Contraste sigue de 50 a 200 y saturación de 0 a 400, sin cambios de comportamiento.
- Mover el brillo conserva el contraste vigente y viceversa. Mover solo la saturación no escribe la curva; mover contraste o brillo no escribe la matriz.
- El valor de contraste o brillo se guarda aunque la escritura falle.
- Sin curva 1D uniforme, contraste y brillo quedan deshabilitados juntos con la nota; la saturación sigue funcionando.
- Mensaje exacto de `ToneCurveUnsupported`: "Esta placa o este modo de pantalla no permite ajustar el contraste ni el brillo."
- Título de la ventana: "Ajustes de pantalla". Alto de ventana según el contenido, sin valor fijo.
- `src/igcl/` no cambia. Todo `unsafe` sigue ahí.
- Textos visibles al usuario en español. Identificadores y mensajes de commit en inglés, sin trailers `Co-Authored-By`.
- Fuera de alcance: animaciones, persistencia, reset rápido, NVIDIA/AMD, el riesgo de la matriz de saturación en enlaces YCbCr.

/// Curva de brillo tipo gamma: `y = x^(1/b)`. `b = 1.0` deja la imagen igual; `> 1.0`
/// aclara medios y sombras; `< 1.0` los oscurece. El negro y el blanco no cambian.
pub fn brightness_curve(b: f64, x: f64) -> f64 {
    x.clamp(0.0, 1.0).powf(1.0 / b)
}

/// Curva de tono que se escribe en la placa: primero contraste, después brillo.
pub fn tone_curve(c: f64, b: f64, x: f64) -> f64 {
    brightness_curve(b, contrast_curve(c, x))
}

    pub fn set_contrast(&mut self, percent: u32) -> Result<(), BackendError> {
        self.contrast =

```rust
#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]

use std::cell::RefCell;
use std::rc::Rc;

use saturacion::backend::BackendError;
use saturacion::controller::Controller;
use saturacion::igcl::IgclBackend;

slint::include_modules!();

type SharedController = Rc<RefCell<Controller<IgclBackend>>>;

/// Muestra el resultado de una escritura: borra el error si salió bien.
fn show_result(ui: &AppWindow, result: Result<(), BackendError>) {
    let message = match result {
        Ok(()) => String::new(),
        Err(e) => e.to_string(),
    };
    ui.set_error_text(message.into());
}

/// Arma el manejador de un slider: pasa el valor redondeado a `apply` y muestra el resultado.
fn slider_handler(
    ui: &AppWindow,
    controller: &SharedController,
    apply: fn(&mut Controller<IgclBackend>, u32) -> Result<(), BackendError>,
) -> impl FnMut(f32) + 'static {
    let ui_weak = ui.as_weak();
    let controller = Rc::clone(controller);
    move |value| {
        let Some(ui) = ui_weak.upgrade() else { return };
        let percent = value.round().max(0.0) as u32;
        let result = apply(&mut *controller.borrow_mut(), percent);
        show_result(&ui, result);
    }
}

fn main() -> Result<(), slint::PlatformError> {
    let ui = AppWindow::new()?;

    let controller = match IgclBackend::new() {
        Ok(backend) => {
            let controller = Controller::new(backend);
            if !controller.supports_tone_curve() {
                ui.set_tone_enabled(false);
                ui.set_tone_note(BackendError::ToneCurveUnsupported.to_string().into());
            }
            Some(Rc::new(RefCell::new(controller)))
        }
        Err(e) => {
            ui.set_error_text(e.to_string().into());
            ui.set_controls_enabled(false);
            None
        }
    };

    if let Some(controller) = &controller {
        ui.on_saturation_changed(slider_handler(&ui, controller, Controller::set_saturation));
        ui.on_contrast_changed(slider_handler(&ui, controller, Controller::set_contrast));
        ui.on_brightness_changed(slider_handler(&ui, controller, Controller::set_brightness));
    }

    let run_result = ui.run();

    // Restaurar aunque el bucle de eventos haya terminado con error.
    if let Some(controller) = controller {
        let _ = controller.borrow_mut().shutdown();
    }
    run_result
}
```
