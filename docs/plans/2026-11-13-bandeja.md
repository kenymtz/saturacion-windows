# Bandeja del sistema — Plan de implementación

**Goal:** Que cerrar la ventana la oculte en la bandeja con los ajustes aplicados, que el ícono la vuelva a abrir y que su menú permita Abrir y Salir, restaurando la imagen solo al salir.

**Architecture:** Un componente Slint `AppTray` que hereda de `SystemTrayIcon` (nativo en Slint 1.18.1) vive en `ui/tray.slint` y se reexporta desde `ui/app.slint`. `src/main.rs` crea la ventana y el ícono, intercepta el cierre de la ventana para ocultarla, y corre `slint::run_event_loop()`, que sigue vivo mientras el ícono esté visible. Al terminar el bucle se restaura como hasta ahora. `controller`, `backend`, `color` e `igcl` no cambian.

**Tech Stack:** Rust stable (MSVC), Slint 1.18.1 (`SystemTrayIcon`, `slint::run_event_loop`, `slint::quit_event_loop`, `Window::on_close_requested`), PowerShell + System.Drawing para generar el ícono.

**Spec:** `docs/specs/2026-11-13-bandeja-design.md`

## Global Constraints

- Solo Windows x64, toolchain `stable-x86_64-pc-windows-msvc`. Sin dependencias nuevas en `Cargo.toml`.
- X de la ventana: oculta la ventana y la app sigue corriendo con los ajustes aplicados, **solo si hay controlador y el ícono se creó**. Si la inicialización falló o no hay ícono, la X termina la app.
- Clic izquierdo en el ícono y "Abrir": muestran la ventana (y la desminimizan). "Salir": termina el bucle.
- Tooltip del ícono: "Ajustes de pantalla". Menú: "Abrir", separador, "Salir".
- Al terminar por cualquier camino se llama a `shutdown()` (restaura solo los bloques escritos), aunque el bucle termine con error.
- Si crear o mostrar el ícono falla y hay controlador, la ventana muestra en el texto de error: "No se pudo crear el ícono de la bandeja; cerrar la ventana termina la app."
- La ventana usa el mismo ícono (`ui/icon.png`) que la bandeja.
- `src/igcl/`, `src/controller.rs`, `src/backend.rs` y `src/color.rs` no cambian.
- Textos visibles al usuario en español. Identificadores y mensajes de commit en inglés, sin trailers `Co-Authored-By`.
- Fuera de alcance: arranque con Windows, instancia única, notificaciones del ícono.

- [ ] **Step 1: Crear el script del ícono**

`ui/make-icon.ps1`:

```powershell
# Genera ui/icon.png (64x64): fondo circular oscuro con tres círculos de color
# superpuestos. Uso, desde la raíz del repo: powershell -ExecutionPolicy Bypass -File ui/make-icon.ps1
$ErrorActionPreference = 'Stop'
Add-Type -AssemblyName System.Drawing

$size = 64
$bmp = New-Object System.Drawing.Bitmap $size, $size
$g = [System.Drawing.Graphics]::FromImage($bmp)
$g.SmoothingMode = [System.Drawing.Drawing2D.SmoothingMode]::AntiAlias
$g.Clear([System.Drawing.Color]::Transparent)

$background = New-Object System.Drawing.SolidBrush ([System.Drawing.Color]::FromArgb(255, 30, 30, 36))
$g.FillEllipse($background, 0, 0, $size - 1, $size - 1)

$radius = 15
$circles = @(
    @{ X = 32; Y = 23; Color = [System.Drawing.Color]::FromArgb(210, 230, 57, 70) },
    @{ X = 23; Y = 39; Color = [System.Drawing.Color]::FromArgb(210, 42, 180, 120) },
    @{ X = 41; Y = 39; Color = [System.Drawing.Color]::FromArgb(210, 69, 123, 230) }
)
foreach ($c in $circles) {
    $brush = New-Object System.Drawing.SolidBrush $c.Color
    $g.FillEllipse($brush, $c.X - $radius, $c.Y - $radius, 2 * $radius, 2 * $radius)
    $brush.Dispose()
}

$out = Join-Path $PSScriptRoot 'icon.png'
$bmp.Save($out, [System.Drawing.Imaging.ImageFormat]::Png)
$g.Dispose()
$bmp.Dispose()
Write-Output "Escrito $out"
```

```slint
export component AppTray inherits SystemTrayIcon {
    icon: @image-url("icon.png");
    tooltip: "Ajustes de pantalla";

    callback open();
    callback quit();

    clicked => {
        root.open();
    }

    Menu {
        MenuItem {
            title: "Abrir";
            activated => {
                root.open();
            }
        }
        MenuSeparator { }
        MenuItem {
            title: "Salir";
            activated => {
                root.quit();
            }
        }
    }
}
```

- [ ] **Step 5: Reemplazar `src/main.rs` completo**

```rust
#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]

use std::cell::RefCell;
use std::rc::Rc;

use saturacion::backend::BackendError;
use saturacion::controller::Controller;
use saturacion::igcl::IgclBackend;
use slint::CloseRequestResponse;

slint::include_modules!();

type SharedController = Rc<RefCell<Controller<IgclBackend>>>;

/// Texto que se muestra si no se pudo crear el ícono de la bandeja.
const TRAY_UNAVAILABLE: &str =
    "No se pudo crear el ícono de la bandeja; cerrar la ventana termina la app.";

/// Muestra el resultado de una escritura: borra el error si salió bien.
fn show_result(ui: &AppWindow, result: Result<(), BackendError>) {
    let message = match result {
        Ok(()) => String::new(),
        Err(e) => e.to_string(),
    };
    ui.set_error_text(message.into());
}

/// Arma el manejador de un slider: pasa el valor redondeado a `apply` y muestra el resultado.
fn slider_handler(
    ui: &AppWindow,
    controller: &SharedController,
    apply: fn(&mut Controller<IgclBackend>, u32) -> Result<(), BackendError>,
) -> impl FnMut(f32) + 'static {
    let ui_weak = ui.as_weak();
    let controller = Rc::clone(controller);
    move |value| {
        let Some(ui) = ui_weak.upgrade() else { return };
        let percent = value.round().max(0.0) as u32;
        let result = apply(&mut *controller.borrow_mut(), percent);
        show_result(&ui, result);
    }
}

/// Crea y muestra el ícono de la bandeja. `None` si la plataforma no lo permite.
fn create_tray(ui: &AppWindow) -> Option<AppTray> {
    let tray = AppTray::new().ok()?;
    tray.show().ok()?;

    let ui_weak = ui.as_weak();
    let show_window = move || {
        if let Some(ui) = ui_weak.upgrade() {
            let _ = ui.show();
            ui.window().set_minimized(false);
        }
    };
    tray.on_clicked(show_window.clone());
    tray.on_open(show_window);
    tray.on_quit(|| {
        let _ = slint::quit_event_loop();
    });
    Some(tray)
}

fn main() -> Result<(), slint::PlatformError> {
    let ui = AppWindow::new()?;

    let controller = match IgclBackend::new() {
        Ok(backend) => {
            let controller = Controller::new(backend);
            if !controller.supports_tone_curve() {
                ui.set_tone_enabled(false);
                ui.set_tone_note(BackendError::ToneCurveUnsupported.to_string().into());
            }
            Some(Rc::new(RefCell::new(controller)))
        }
        Err(e) => {
            ui.set_error_text(e.to_string().into());
            ui.set_controls_enabled(false);
            None
        }
    };

    if let Some(controller) = &controller {
        ui.on_saturation_changed(slider_handler(&ui, controller, Controller::set_saturation));
        ui.on_contrast_changed(slider_handler(&ui, controller, Controller::set_contrast));
        ui.on_brightness_changed(slider_handler(&ui, controller, Controller::set_brightness));
    }

    // El ícono debe vivir hasta el final de `main`: al soltarlo desaparece de la bandeja.
    let tray = create_tray(&ui);
    if tray.is_none() && controller.is_some() {
        ui.set_error_text(TRAY_UNAVAILABLE.into());
    }

    // Con controlador e ícono, la X solo oculta la ventana (el ícono mantiene vivo el
    // bucle). Sin alguno de los dos, la X termina la app.
    let keep_running_in_tray = controller.is_some() && tray.is_some();
    ui.window().on_close_requested(move || {
        if !keep_running_in_tray {
            let _ = slint::quit_event_loop();
        }
        CloseRequestResponse::HideWindow
    });

    ui.show()?;
    let run_result = slint::run_event_loop();

    // Restaurar aunque el bucle de eventos haya terminado con error.
    if let Some(controller) = controller {
        let _ = controller.borrow_mut().shutdown();
    }
    drop(tray);
    run_result
}
```

Notas para adaptar solo si el compilador lo exige, sin cambiar comportamiento:
- Si `show_window.clone()` no compila porque el cierre no es `Clone`, crear dos cierres iguales, cada uno con su propio `ui.as_weak()`.
- Si `AppTray` no expone `show()`, quitar esa línea (el ícono es visible por defecto).
